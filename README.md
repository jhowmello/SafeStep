# SafeStep

Este é um aplicativo móvel desenvolvido para a área de Segurança do Trabalho, com o objetivo de fornecer ferramentas e recursos para promover um ambiente de trabalho mais seguro e saudável.

## 🚀 Começando

Estas instruções permitirão que você obtenha uma cópia do projeto em operação na sua máquina local para fins de desenvolvimento e teste.

### Pré-requisitos

O que você precisa para instalar o software:

- [Node.js](https://nodejs.org/)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)

### Instalação

Siga estas etapas para configurar o ambiente de desenvolvimento:

1. Clone o repositório:
   ```bash
   git clone https://github.com/jhowmello/SafeStep.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd SafeStep
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento do Expo:
   ```bash
   npm start
   ```
